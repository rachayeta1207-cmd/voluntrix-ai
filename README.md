# Voluntrix AI

## 🚀 Overview
Voluntrix AI is an AI-powered platform that helps NGOs efficiently manage and allocate volunteers using intelligent matching.

## ❗ Problem
Manual coordination of volunteers leads to delays, inefficiency, and poor resource utilization.

## 💡 Solution
Our platform uses AI to match volunteers to tasks based on skills, location, and availability.

## ✨ Features
- AI-based volunteer matching  
- Real-time task management  
- Location-based allocation  
- Dashboard for NGOs  

## 🧠 Tech Stack
- React / Flutter  
- Firebase  
- Google Gemini API
